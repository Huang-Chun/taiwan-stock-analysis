資料同步 Admin
POST
/api/admin/sync
一鍵同步（SSE streaming）：全市場參考股價（近2個月）+ 覆蓋清單財報（近4季）+ 覆蓋清單月營收
POST
/api/admin/sync-history
補歷史參考股價（SSE streaming）body: { months: 1-120 }
POST
/api/admin/daily-sync
手動觸發每日自動同步（跟 cron 排程同一函式）：股價+覆蓋清單月營收/財報，並偵測數字變化寫入 data_change_log
觀察總覽 Framework
GET
/api/dashboard
覆蓋清單所有股票依產業分組，含資料新鮮度、下一次月營收/財報預期公布日(財報優先採官方公告日期)、近期重大訊息標記
GET
/api/dashboard/upcoming
未來N天內覆蓋清單哪些股票要公布月營收/財報/法說會?days=7
GET
/api/sync-runs/latest
最近一次同步偵測到的數字變化清單?run_id= 可指定特定一次
GET
/api/sync-runs
近期同步執行紀錄（最多20筆）
GET
/api/material-announcements
官方重大訊息：注意股清單、公佈自結、財報董事會日期(排程/已決議)、法說會排程?days=14 &coverage_only=true
